Referans · Callback · Higher-Order · Arrow

Her örneği ▶ Çalıştır ile çalıştır, çıktıyı gör. Modül 1'den başlayıp modül 2'ye ilerliyoruz.

Bölüm 1 · Modül 1 — Komplike veri türlerini kopyalamak

1 · Basit veri türü = fotokopi 📄

Sayı, string, boolean kopyalanınca yeni bir kopya oluşur. Kopyayı değiştirmek aslını etkilemez.

let a = 5;
let b = a;        // fotokopi çektik
b = 10;           // kopyanın üstüne yazdık

console.log(a);   // ?
console.log(b);   // ?

2 · Komplike veri türü = aynı deftere ikinci etiket 🏷️

Array ve objelerde = kopya çıkarmaz. Aynı deftere ikinci bir isim etiketi yapıştırır. Defter tek.

const sepet1 = ["elma"];
const sepet2 = sepet1;     // aynı deftere 2. etiket
sepet2.push("armut");     // sepet2'ye ekledik...

console.log(sepet1);        // ...peki sepet1?
console.log(sepet1 === sepet2);

3 · Soruyu şık şık test edelim

"Aşağıdakilerden hangisi komplike veri türlerinin kopyalanmasında doğru bir ifadedir?" — her şıkkı yukarıdaki kodla karşılaştır:

1 "Eşittir operatörü ile doğrudan kopyalanabilir." → ❌ = kopyalamıyor, sadece isim veriyor.
2 "Tamamen bağımsız yeni bir kopya oluşturulur." → ❌ Bağımsız olsaydı sepet1 değişmezdi. Ama değişti.
3 "Hafızada yeni bir alan ayrılır." → ❌ Yeni alan olsaydı sepet1 === sepet2 false çıkardı. true çıktı → ikisi aynı yer.
4 "Aslında aynı veriye farklı bir isim atanmış olur." → ✅ Tek defter, iki etiket.
  • 2 ve 3 numaralı şıklar basit veri türleri için doğru (fotokopi). Soru komplike olanları soruyor — tuzak burada.

4 · Peki gerçekten kopyalamak istersem? → spread ...

Modül 2'de gördüğümüz spread, elemanları yeni bir array'e döker. Bu sefer gerçekten yeni defter.

const sepet1 = ["elma"];
const sepet3 = [...sepet1];   // YENİ defter, içine elma'yı yazdık
sepet3.push("kiraz");

console.log(sepet1);
console.log(sepet3);
console.log(sepet1 === sepet3);
Bölüm 2 · Fonksiyon bir değerdir → callback

5 · selamla ile selamla() aynı şey değil

Parantezsiz = fonksiyonun kendisi (tarif). Parantezli = şimdi çalıştır, sonucunu ver (yemek).

function selamla() {
  return "Merhaba!";
}

console.log(selamla);     // tarif
console.log(selamla());   // yemek

6 · setTimeout'a tarif ver, yemek verme ⏰

setTimeout'a "2 saniye sonra bunu çalıştır" diyoruz. Ona fonksiyonun kendisini vermeliyiz.

function zamanDoldu() {
  console.log("Zaman doldu!");
}

setTimeout(zamanDoldu, 2000);      // ✅ tarif → 2 sn sonra çalışır
setTimeout(zamanDoldu(), 2000);    // ❌ () ile HEMEN çalışır, beklemez
  • zamanDoldu() yazınca JS önce onu hemen çalıştırır, dönen sonucu (undefined) setTimeout'a verir.
  • Arrow ile de yazabilirsin: setTimeout(() => console.log("Zaman doldu!"), 2000)
Bölüm 3 · Callback ile Higher-Order fonksiyonun farkı

7 · Aynı satırda iki rol

Bir fonksiyon başka bir fonksiyonu parametre olarak alıyorsa (veya fonksiyon döndürüyorsa) → higher-order. Ona verilen fonksiyon → callback.

const sayilar = [3, 5, 20, 32, 9, 16];

function ondanBuyukMu(sayi) {
  return sayi > 10;
}

const sonuc = sayilar.filter(ondanBuyukMu);
//                   ▲▲▲▲▲▲  ▲▲▲▲▲▲▲▲▲▲▲▲
//          higher-order      callback
//      (fonksiyon ALAN)      (VERİLEN fonksiyon)
Higher-order (alan)Callback (verilen)
sayilar.filter( ... )ondanBuyukMu
sayilar.map( ... )(m) => "Favori " + m
sayilar.reduce( ... , 0)(toplam, yeni) => toplam + yeni
setTimeout( ... , 2000)zamanDoldu
  • Benzetme: kargo firması higher-order, paket callback. Firma paketi alır, zamanı gelince teslim eder (çalıştırır).
  • filter, map, reduce, sort, setTimeout → hepsi yüksek dereceli (higher-order) fonksiyon. Çünkü hepsi parametre olarak fonksiyon alıyor.

8 · Kendi higher-order fonksiyonumuzu yazalım

Özel bir şey değil: parametresi fonksiyon olan herhangi bir fonksiyon.

function ikiKereYap(islem) {   // higher-order: fonksiyon alıyor
  islem();
  islem();
}

function alkis() {             // callback olarak verilecek
  console.log("👏");
}

ikiKereYap(alkis);               // tarif veriyoruz, () yok
Bölüm 4 · Arrow fonksiyona çevirmek — 3 adım

9 · Klasik → arrow

Her adımda sadece bir şeyi değiştiriyoruz:

// 0) Klasik
function kirktanBuyukMu(sayi) {
  return sayi > 40;
}

// 1) Anonim fonksiyonu bir değişkene ata    → isim  const'tan sonraya taşındı
const kirktanBuyukMu2 = function (sayi) {
  return sayi > 40;
};

// 2) "function" kelimesini sil, parantezden sonra  =>  koy
const kirktanBuyukMu2 = (sayi) => {
  return sayi > 40;
};

// 3) Tek satırsa: { } ve return'ü sil         → otomatik return eder
const kirktanBuyukMu2 = (sayi) => sayi > 40;

10 · Arrow yazarken kontrol listesi ✅

Kontrol etHatalıDoğru
1. const + isim + = var mı? const toplama4 (z, w) => z + w const toplama4 = (z, w) => z + w
2. İstenen isim mi? const toplama = ... (soru toplama3 istiyor) const toplama3 = ...
3. function kelimesi gitti mi? const f = function (x) => ... const f = (x) => ...
4. { } varsa return da var mı? (x, y) => { x + y } → undefined (x, y) => { return x + y } veya (x, y) => x + y
Bölüm 5 · reduce — hepsini bir araya getirelim

11 · reduce adım adım

reduce, array'i tek bir değere indirger. Her adımda callback'e iki şey verir: şimdiye kadarki toplam ve sıradaki yeni eleman.

const sayilar = [5, 3, 8, 1];

function topla(toplam, yeni) {     // callback
  return toplam + yeni;
}

const sonuc = sayilar.reduce(topla, 0);   // reduce = higher-order
//                                       ▲ 0 = başlangıç değeri

// Arrow ile tek satırda aynısı:
const sonuc2 = sayilar.reduce((toplam, yeni) => toplam + yeni, 0);

12 · Pratikteki reduce sorusunu şık şık test edelim

"Aşağıdakilerden hangileri reduce metodunun özelliklerindendir?"

1 "Orijinal diziyi değiştirir." → ❌ reduce'tan sonra sayilar aynı kalıyor (aşağıda test ediyoruz).
2 "Arraydeki tüm elemanları tek bir değere indirger." → ✅ [5, 3, 8, 1] → 17
3 "Yalnızca sayıları toplamak için kullanılır." → ❌ String'leri birleştirmek, en büyüğü bulmak için de kullanılır.
4 "Yüksek dereceli bir fonksiyondur." → ✅ Parametre olarak bir fonksiyon alıyor (topla). Örnek 7'deki tabloyu hatırla.
const sayilar = [5, 3, 8, 1];
const toplam = sayilar.reduce((t, y) => t + y, 0);
console.log(sayilar);                   // şık 1: değişti mi?

const kelimeler = ["Merhaba", "dünya", "!"];
const cumle = kelimeler.reduce((t, y) => t + " " + y);   // şık 3: sadece sayı mı?

const enBuyuk = sayilar.reduce((t, y) => (y > t ? y : t));  // şık 3: toplamaktan başka

Özet

  • Basit veri = ile kopyalanır (fotokopi). Array/obje = ile kopyalanmaz, aynı şeye ikinci isim olur (etiket). Gerçek kopya: [...dizi], {...obje}.
  • fonk = tarif, fonk() = şimdi çalıştır. Başka bir fonksiyona verirken parantez koyma.
  • Higher-order = fonksiyon alan (filter, map, reduce, setTimeout). Callback = ona verilen fonksiyon.
  • Arrow = const isim = (parametre) => ... — = işaretini ve ismi unutma.
  • reduce = array'i tek değere indiren higher-order fonksiyon. Callback'e (toplam, yeni) verir, orijinal diziyi değiştirmez.
